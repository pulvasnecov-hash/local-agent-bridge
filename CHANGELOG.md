# Changelog

## 0.1.0 — 2026-10-27

- Самостоятельный пакет: мост, общая доска и запускатель OpenCode.
- Переносимые настройки, поиск установленного OpenCode, установщик для Windows.
- Передача UTF-8 файла без shell, закрытый stdin, отдельный сервер OpenCode.
- Идентификаторы задач, записи о запуске и завершении, необязательный тайм-аут.
- Блокировка журнала для одновременных локальных читателей и писателей.
- Документация на русском и английском, MIT, тесты и конфигурация GitHub Actions.
