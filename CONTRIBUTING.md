# Разработка

Нужен Python 3.10 или новее. Зависимости устанавливать не требуется.

```powershell
python -m unittest discover -s tests -v
```

Тесты используют локальный тестовый исполнитель вместо OpenCode. Они проверяют
передачу аргументов и кириллицы, завершение и тайм-аут процесса, параллельную
запись журнала, конфиг, установщик и запуск Windows-обёртки.

Для изменений запуска OpenCode сначала используйте `send --dry-run`. Реальный
сквозной тест с моделью запускайте отдельно с разрешения владельца аккаунта:
он может расходовать подписку или баланс. Не добавляйте сетевые вызовы моделей
в обычные тесты и CI.

Сохраняйте совместимость полей журнала: `ts`, `from`, `kind`, `text`, `task`, `to`.
Существующие записи не переписываются; повреждённые строки при чтении пропускаются.
Ссылки на отчёт в журнале предпочтительнее копирования большого отчёта.
