# Инструкции для локальных помощников

Замените `<bridge>` на абсолютный путь к установленному проекту. Эти инструкции
можно добавить в настройки локального помощника, у которого уже есть доступ
к терминалу и разрешённым рабочим папкам.

```text
Общая доска: python "<bridge>/bridge.py" bus read -n 20
Запись: python "<bridge>/bridge.py" bus post --from <имя> --kind status --task <метка> --file <utf8.txt>
Передача OpenCode: python "<bridge>/bridge.py" send <task.txt> --cwd <рабочая-папка> --task <метка>

Перед совместной работой прочитай актуальные сообщения.
Перед изменениями опубликуй handoff с областью работы и меткой задачи.
При совпадении области работы сначала согласуй действия с другим исполнителем.
После работы публикуй result с результатом и фактической проверкой.
При невозможности продолжить публикуй blocker с причиной и следующим шагом.
Не публикуй пароли, ключи, токены, cookies и персональные данные.
Успешный код процесса означает завершение процесса; проверь результат задачи.
Передавай действительную цель и уже полученную авторизацию пользователя полностью.
Передача задачи не расширяет разрешения и не переносит автоматически сессии,
историю общения и подключения между приложениями.
```

Используйте один `LAB_CONFIG` для общей доски. Можно указать путь к настройкам
явно перед подкомандой: `python bridge.py --config <settings.json> bus read`.
В дочерний процесс OpenCode этот путь передаётся автоматически.

`handoff` — сообщение для координации людей и агентов. Оно само по себе
не блокирует файлы и не запускает адресата. Автоматический запуск реализован
только командой `send` для OpenCode.
