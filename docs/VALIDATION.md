# Проверка версии 0.1.0

Дата: 2026-10-27. Локальная среда: Windows, Python 3.14.9.

| Проверка | Результат |
|---|---|
| `python -m unittest discover -s tests -v` | 20 тестов прошли |
| Передача task-файла локальному тестовому исполнителю | Проверены аргументы, рабочая папка, UTF-8 и закрытый stdin |
| Доска | Проверены фильтры, повреждённые строки, защита от некоторых секретов и 12 параллельных записей |
| Жизненный цикл процесса | Проверены успешное завершение, код ошибки и остановка по тайм-ауту |
| Windows | Проверены `.cmd`-обёртка и сохранение конфига при повторной установке |
| `doctor --json` на установленном OpenCode | Исполняемый файл обнаружен |
| `send examples/task.txt --dry-run` | Команда сформирована; модель не вызывалась |

Первый запуск тестов внутри ограниченной песочницы остановился на запрете записи
во временную папку. Повторный разрешённый запуск вне песочницы завершился успешно.
Это ограничение окружения, а не результат тестирования логики проекта.

Новый реальный вызов модели для этой версии не выполнялся. Сквозные проверки
процесса использовали локальный тестовый исполнитель, без расхода на модель.
Первоначальный рабочий мост до выделения в этот проект ранее проходил реальную
передачу задания Codex → OpenCode с обратным ответом; это отдельное свидетельство,
которое не заменяет проверку новой версии с реальным провайдером.

Linux и Python 3.10/3.13 включены в конфигурацию CI. Фактический результат
удалённого запуска смотрите в GitHub Actions; локальный результат выше относится
только к указанной Windows-среде.
